# d9-ssu_news_collection

Модуль Drupal 9 для отображения коллекций новостей с расширенными возможностями фильтрации и пагинации.

## Описание проекта

Модуль `news_collection` предназначен для организации и отображения новостей на сайте с поддержкой:
- Фильтрации новостей по различным критериям
- Пагинации результатов
- Отображения новостей по подразделениям
- Интеграции с таксономией Drupal

## Основные возможности

### Страницы и маршруты

1. **Главная страница новостей** (`/news-list`)
   - Отображение всех новостей с пагинацией
   - Фильтрация по различным параметрам
   - По умолчанию показывает только новости без привязки к подразделениям

2. **Новости подразделения** (`/struktura/{subdivision}/news`)
   - Отображение новостей конкретного подразделения
   - Автоматическая валидация существования страницы подразделения
   - Поддержка фильтрации и пагинации

3. **Новости дочернего подразделения** (`/struktura/{subdivision}/{subdivision_child}/news`)
   - Отображение новостей дочернего подразделения
   - Поддержка вложенной структуры подразделений

4. **Новости подразделения второго уровня** (`/struktura/{subdivision}/{subdivision_child}/{subdivision_child2}/news`)
   - Отображение новостей подразделения третьего уровня вложенности

### Функциональность фильтрации

Модуль поддерживает следующие типы фильтров:

- **Поиск по заголовкам** - текстовый поиск в заголовках новостей
- **Фильтр по рубрикам** - выбор из таксономии `heading`
- **Фильтр по дате** - выбор диапазона дат публикации (с использованием календаря Air Datepicker)
- **Фильтр по тегам** - выбор из таксономии `news_tags`
- **Фильтр по ключевым словам** - выбор из таксономии `news_keywords`
- **Главные новости** - фильтр по флагу главной новости (`field_news_main_flag`)
- **Фильтр по подразделениям** - фильтрация по участникам событий и связанным подразделениям
- **Фильтр по участникам** - фильтрация по участникам событий

### Компоненты

#### Контроллеры

- `NewsCollectionListing` - основной контроллер для главной страницы новостей
- `NewsSubdivisionListing` - контроллер для новостей подразделений
- `NewsSubdivisionChildListing` - контроллер для новостей дочерних подразделений
- `NewsSubdivisionChildListing2` - контроллер для подразделений второго уровня

#### Формы

- `NewsFilter` - форма фильтрации новостей с поддержкой всех типов фильтров

#### Блоки

- `NewsListBlock` - блок для отображения списка новостей на главной странице

#### Шаблоны Twig

- `news-collection-listing.html.twig` - шаблон главной страницы новостей
- `news-subdivision-listing.html.twig` - шаблон страницы новостей подразделения
- `news-subdivision-child-listing.html.twig` - шаблон страницы новостей дочернего подразделения
- `news-subdivision-child-listing2.html.twig` - шаблон страницы новостей подразделения второго уровня
- `news-card.html.twig` - шаблон карточки отдельной новости

### Особенности реализации

- **Пагинация**: 16 новостей на страницу с поддержкой навигации "предыдущая/следующая" и перехода на несколько страниц вперед/назад
- **Обработка изображений**: автоматическое применение стилей изображений Drupal (`416xauto`)
- **Слайдер изображений**: поддержка множественных изображений в шапке новости с использованием Swiper.js
- **Валидация**: проверка существования страниц подразделений перед отображением новостей
- **Кэширование**: отключено для страниц новостей (`no_cache: TRUE`)

### Зависимости

- Drupal 9.x
- Таксономии: `heading`, `news_tags`, `news_keywords`
- Тип контента: `news` со следующими полями:
  - `field_heading` - рубрика
  - `field_news_announce` - анонс новости
  - `field_publ_date` - дата публикации
  - `field_news_header_slider` - слайдер изображений в шапке
  - `field_news_main_flag` - флаг главной новости
  - `field_news_link` - связь с подразделением
  - `field_news_participant_division` - подразделение-участник события
  - `field_news_participant` - участник события
  - `field_news_tag` - теги новости
  - `field_news_keywords` - ключевые слова
  - `field_video_v_shapke_novosti` - видео в шапке новости

### Ресурсы (Assets)

Модуль включает следующие ресурсы:

**CSS:**
- `air-datepicker.css` - стили календаря для выбора дат

## Установка

1. Скопируйте модуль в директорию `modules/custom/`
2. Включите модуль через административный интерфейс Drupal или командой:
   ```bash
   drush en news_collection
   ```
3. Настройте права доступа для маршрутов модуля
4. Убедитесь, что все необходимые типы контента и таксономии созданы

## Использование

После установки модуль автоматически создает маршруты для отображения новостей. Блок `NewsListBlock` можно добавить на страницу через административный интерфейс Drupal в разделе "Структура" → "Блоки".

## Разработка

Модуль разработан для Drupal 9 и следует стандартам кодирования Drupal. Все контроллеры наследуются от `ControllerBase`, формы от `FormBase`.
